API testing with Postman

For each endpoint I check the following.

  • Status code matches the API contract.
  • Response body has the expected structure and data types.
  • Required fields are present and values are valid.
  • Response time is within the agreed limit.
  • Headers such as Content-Type are correct.
  • Negative cases return suitable error codes and messages.
pm.test("Status code is 200", function () {
  pm.response.to.have.status(200);
});
pm.test("Response is JSON", function () {
  pm.response.to.be.json;
});
pm.test("Response time is under 2000 ms", function () {
  pm.expect(pm.response.responseTime).to.be.below(2000);
});
